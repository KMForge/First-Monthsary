# Our First Bloom

A personal first-monthsary website with animated lilies, six photo memories, an interactive garden, a love letter, and optional music. Designed for desktop and phones.

## Deploy to Vercel
1. Import KMForge/First-Monthsary into Vercel.
2. Keep the Root Directory at the repository root. Framework Preset: Other.
3. The included vercel.json serves dist without an install or build command.
4. Deploy and use the production URL for sharing and the QR code.

## Edit the website
The published files are in dist/. Edit dist/content.js for captions, the relationship date, personal notes, and the letter. Photos are in dist/assets/images/. The opening photo is pic5.jpg.

The repository also contains source copies at its root. Keep those copies synchronized with dist when editing. No packages or build tools are needed to run the site.

Open dist/index.html directly, or serve dist with a local HTTP server. Google Fonts use an internet connection; personal photos are stored locally in the project.

## Features
- Glowing SVG lilies and an interactive memory garden.
- Six-photo gallery with keyboard and swipe navigation.
- Personal notes and an opening love letter.
- Days-together counter using Asia/Manila dates, starting September 19, 2026.
- Optional original synthesized melody, activated by a tap.
- Reduced-motion support and responsive desktop/phone layouts.
